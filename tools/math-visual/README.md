# Math visual check tool

Снимает окно MarkMello и готовит кадры для визуальной проверки формул моделью
с vision-входом (`bynara/muse-spark-1.3-contributor`).

## Зачем

Формулы оцениваются только глазами: перехлёст строк, размер шрифта, читаемость
вложенных дробей нельзя проверить юнит-тестом. Раньше это делалось вручную и
скриншот регулярно ловил чужое окно (проводник, браузер, игра) — проверка молча
проваливалась.

## Состав

- `capture.ps1` — запускает MarkMello с переданным `.md`, дожидается окна,
  поднимает его на передний план и снимает **регион окна** (а не весь экран),
  затем пишет кадры в `out/`.
- `review.md` — шаблон промпта для модели с vision-входом.
- `run.ps1` — одной командой: capture → список файлов → печать промпта.

## Использование

```powershell
# 1. Снять кадры документа (окно OpenCode/терминал не пострадает)
powershell -ExecutionPolicy Bypass -File tools\math-visual\capture.ps1 `
    -Document H:\work\M\ELMisFast\todo.md -Slices 3

# 2. Отдать промпт модели с vision
#    (см. tools\math-visual\review.md, подставьте имена файлов из out\)
```

## Что важно

- Снимается **регион окна MarkMello**, а не экран: перекрытие другими окнами
  не портит кадр.
- `-Slices N` режет окно по горизонтали на N полос — удобно, чтобы формулы
  гарантированно попали в кадр целиком.
- Временные кадры живут в `tools/math-visual/out/` и в git не попадают.
- Никаких заглушек: это штатное приложение, запущенное с реальным документом.
