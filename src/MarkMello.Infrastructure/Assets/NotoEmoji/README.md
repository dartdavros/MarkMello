# Noto Emoji subset

This directory contains a compact subset of PNG assets from Google Noto Emoji:

https://github.com/googlefonts/noto-emoji

The assets are used only when exporting Markdown emoji to PDF, so common emoji
can be embedded as color images instead of monochrome PDF text glyphs.
